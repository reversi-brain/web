
# Reversi Brain - Web Client

リバーシ（オセロ）プロジェクトのフロントエンド（Webブラウザ用）クライアントです。
React / Next.js を使用して構築されています。

## プロジェクト概要

本リポジトリは、マルチプラットフォーム（Web, iOS, Android）展開を想定したリバーシプロジェクトのうち、Webクライアントを担当します。

現在は「Phase 1」として、フロントエンド単体で完結する基本的なゲームロジック（人間 vs 人間）と、モダンなスコアボードUIが実装されています。
今後のフェーズにて、Python APIサーバー（バックエンド）と通信し、AI（CPU）との対戦機能が追加される予定です。

## 使用技術
- React
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## 環境構築と起動方法

### 1. 依存パッケージのインストール
`bash
npm install
`

### 2. 開発サーバーの起動
`bash
npm run dev
`

ブラウザで [http://localhost:3000](http://localhost:3000) にアクセスすると、ゲーム画面が表示されます。

## 実装済みの機能 (Phase 1)
- 任意の偶数サイズに対応した動的盤面レイアウト（デフォルト 8x8）
- 石の配置と、8方向の裏返し判定
- 次のターンに打てる場所がない場合の「パス」自動判定
- 双方が打てなくなった際の「ゲーム終了」判定
- 現在のターンと黒・白の石の数をリアルタイム表示するリッチなスコアボードUI
